\section*{Introduction}

This folder is for splitting large documents into manageable sections.

\subsection*{Examples}

Inline code: \code{src/index.tex}. A key combo: \kbd{Ctrl+C}. A URL: \urltext{https://example.com}{example.com}.

\begin{tightitemize}
  \item Reusable macros live under \code{src/components/}.
  \item Add citations with \code{biblatex}: \cite{example}.
\end{tightitemize}

\begin{lstlisting}[language=bash,caption={Build locally}]
./scripts/build.sh
./scripts/build.sh src/index.tex dist xelatex
\end{lstlisting}
